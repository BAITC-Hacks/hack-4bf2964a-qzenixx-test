# FAQ-бот о репетиции

Терминальный бот отвечает на пять заранее известных вопросов о репетиции: время, команда, трек, сдача и призы. Он не использует внешние сервисы: ищет совпадения по ключевым словам из `faq.txt`. Если ключевых слов нет, бот отвечает: «Не знаю.»

## Запуск

Нужен Node.js 18 или новее. В корне репозитория выполните:

```bash
node faq_bot.js
```

Введите вопрос и нажмите Enter. Для завершения напишите `выход` или нажмите `Ctrl+C`.

Примеры вопросов: «Сколько длится репетиция?», «Куда сдавать работу?», «Какие будут призы?».

## Состав

- `faq.txt` — пять пар «вопрос–ответ» и ключевые слова;
- `faq_bot.js` — интерактивный терминальный бот;
- `README.md` — инструкция по запуску.

## Классификатор обращений

В проект также добавлен небольшой классификатор пяти готовых обращений. Он читает их из `messages.txt`, определяет категорию — «справка», «жалоба» или «другое» — и печатает черновик ответа на русском. Для работы используются простые правила по ключевым словам, без внешних сервисов.

Запуск классификатора:

```bash
node classifier.js
```

- `messages.txt` — пять обращений из задания;
- `classifier.js` — скрипт классификации и подготовки ответов.

## Проверка дефекта по изображению

`defect_detector.js` принимает путь к PNG-файлу и проверяет, много ли на нём красного цвета. Если красные пиксели занимают больше 30% изображения, он печатает `DEFECT`, иначе — `OK`. В репозитории есть два примера: `ok.png` и `defect.png`.

Запуск:

```bash
node defect_detector.js ok.png
node defect_detector.js defect.png
```

Первый пример выдаёт `OK`, второй — `DEFECT`.
